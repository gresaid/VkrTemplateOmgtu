# Главное из правил оформления отчетов и ПЗ

Источник: [Правила оформления отчетов и ПЗ.docx.txt](/Users/vladimirgres/Documents/Thesis/Documents/Правила%20оформления%20отчетов%20и%20ПЗ.docx.txt)

## 1. Обязательная структура документа

Для отчета / пояснительной записки используется такая структура:

1. Титульный лист
2. `РЕФЕРАТ`
3. `СОДЕРЖАНИЕ`
4. `ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ` (если нужен)
5. `ВВЕДЕНИЕ`
6. Основная часть
7. `ЗАКЛЮЧЕНИЕ`
8. `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`
9. `ПРИЛОЖЕНИЕ А`
10. `ПРИЛОЖЕНИЕ Б` и далее при необходимости

Важно: каждая структурная единица начинается с новой страницы.

## 2. Базовые параметры оформления

- Формат страницы: A4
- Поля: верх 2 см, низ 2 см, левое 3 см, правое 1.5 см
- Основной шрифт: `Liberation Serif` или `CMU`
- Основной размер шрифта: `14 pt`
- Межстрочный интервал: `1.5`
- Абзацный отступ: `1.25 см`
- Выравнивание основного текста: по ширине
- Табуляцию не использовать
- В таблицах допустимо уменьшение шрифта, но не менее `10 pt`

Для отчета по практике указан отдельный межстрочный интервал: множитель `1.2`.

## 3. Заголовки

### Структурные разделы

К ним относятся:

- `РЕФЕРАТ`
- `СОДЕРЖАНИЕ`
- `ВВЕДЕНИЕ`
- `ЗАКЛЮЧЕНИЕ`
- `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`
- `ПРИЛОЖЕНИЕ ...`

Правила:

- писать `CAPS LOCK`
- без полужирного
- по центру
- без абзацного отступа
- после заголовка пустая строка

### Заголовки основной части

Разделы:

- нумерация: `1`, `2`, `3` без точки
- полужирный
- с абзацного отступа
- по ширине или по левому краю
- отделяются пустой строкой сверху и снизу

Подразделы:

- нумерация: `1.1`, `1.2`, `1.3`
- без точки в конце номера
- полужирный
- с абзацного отступа
- по ширине или по левому краю

Пункты:

- нумерация: `1.1.1`, `1.1.2`, `1.1.3`
- без точки в конце номера
- без полужирного
- с абзацного отступа
- по ширине или по левому краю

## 4. Требования к содержанию ключевых разделов

### Введение

- объем: примерно 2 страницы, но не менее 1
- должно содержать актуальность
- затем формулируется цель
- далее перечисляются задачи
- задачи должны задавать структуру основной части

### Заключение

- объем: 0.5-1 страница
- подводятся итоги по поставленным задачам
- желательно указать возможные направления развития работы

### Реферат

Должен включать:

- объем работы
- число рисунков
- число таблиц
- число источников
- ключевые слова
- объект исследования
- предмет исследования
- цель работы
- что сделано в процессе выполнения
- что получено в результате

## 5. Текст и язык оформления

- использовать только кавычки `«...»`
- различать дефис `-` и тире `–`
- длинное тире `—` не использовать
- английские слова, названия методов и инструментов оформлять курсивом

## 6. Списки

Допустимые варианты:

- тире `–`, если порядок не важен
- арабская цифра со скобкой, если порядок важен
- маленькая буква русского алфавита со скобкой, если порядок важен

Для списка источников:

- использовать арабские цифры
- без скобки
- без точки

## 7. Код

Код можно оформлять отдельным блоком или встраивать в текст.

Правила для блока кода:

- сверху и снизу пустая строка
- шрифт `Deja Vu Sans`
- размер `11 pt`
- межстрочный интервал одинарный

## 8. Формулы

- формулы могут быть встроены в текст
- если формула вынесена в отдельную строку, то она:
  - выравнивается по центру
  - нумеруется
  - отделяется пустой строкой сверху и снизу

## 9. Рисунки

- рисунок выравнивается по центру
- до рисунка в тексте обязательно должна быть ссылка на него
- подпись размещается под рисунком
- формат подписи: `Рисунок N – Название`
- подпись без точки в конце
- рисунок с подписью отделяется пустой строкой сверху и снизу

## 10. Таблицы

- до таблицы в тексте обязательно должна быть ссылка на таблицу
- таблица настраивается с автоподбором по ширине окна
- название таблицы ставится сверху слева
- формат названия: `Таблица N – Название`
- точка в конце названия не ставится
- таблица и ее название отделяются пустой строкой сверху и снизу
- при переносе на следующую страницу писать: `Продолжение таблицы N`
- на новой странице повторять заголовки столбцов

## 11. Приложения

- каждое приложение начинается с новой страницы
- заголовок вида: `ПРИЛОЖЕНИЕ А`
- обязательное приложение: листинг программы
- обязательны также все приложения, на которые есть ссылки в тексте
- остальное можно оформлять как справочные приложения

## 12. Что обязательно заложить в шаблон

- готовые стили для основного текста, структурных заголовков, разделов, подразделов, пунктов
- отдельный стиль для подписи рисунка
- отдельный стиль для названия таблицы
- отдельный стиль для кода
- автоматическое содержание по заголовкам 1-3 уровня
- заготовки для `РЕФЕРАТ`, `ВВЕДЕНИЕ`, `ЗАКЛЮЧЕНИЕ`, `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`, `ПРИЛОЖЕНИЕ А`

## 13. Что в исходнике почти не раскрыто

В тексте почти нет подробных правил для:

- титульного листа
- нумерации страниц
- точного оформления библиографических описаний

Для этих частей лучше опираться на отдельный готовый шаблон кафедры / вуза.
